## Fix

- 오버레이에서 통계, 그래프, 노브, 플러그인 요소가 마우스를 받지 못해 옮기거나 우클릭할 수 없던 문제 수정
- 숨긴 키가 오버레이에 계속 보이던 문제 수정
- 화면 배율이 바뀐 뒤 오버레이 요소의 마우스 반응 영역이 실제 위치와 어긋나던 문제 수정
- 마우스 반응 영역 정보가 유실되면 오버레이를 다시 열기 전까지 요소를 조작할 수 없던 문제 수정
- 색상 피커 같은 팝업이 기준 위치를 반복해서 다시 잡으며 앱이 멈추던 문제 수정
- 그래프가 같은 값을 반복해서 갱신하며 앱이 멈추던 문제 수정
- Windows에서 투명 효과를 끄거나 배터리 절약 모드가 켜지면 앱 UI의 유리 질감이 사라지던 문제 수정
