## New

### 디자인 개편 및 사이드 패널

- 앱 전체 디자인 개편
  - Pretendard Variable을 기본 글꼴로 적용하고 퍼플 계열 강조색과 반투명 유리 질감을 도입했습니다.
  - 메인 툴바, 속성 패널, 설정, 모달, 팝업, 피커, 미니맵의 디자인과 동작을 하나의 기준으로 통일했습니다.
  - 첫 실행 기본 프리셋과 키, 노브, 그래프, 통계, 카운터, 노트의 기본 스타일을 새로 구성했습니다.
  - 앱 아이콘을 교체했습니다.
  - 신규 키 디자인은 [@DominoKorean](https://github.com/DominoKorean) 님의 [커스텀 CSS 스킨](https://github.com/DominoKorean/DM-Note-skins)에서 영감을 받아 만들었습니다.

- 설정을 사이드 패널로 이동
  - 사운드, 폰트, 커스텀 CSS, 플러그인 설정을 별도 관리 창 없이 현재 화면에서 바로 관리할 수 있습니다.
  - 피커와 편집기는 패널 안쪽 하위 페이지나 전체 화면 시트로 열립니다.
  - 팝업과 모달의 키보드 포커스, Tab 이동, Escape 동작, 접근성 안내를 정리했습니다.

- 속성 패널 분리 창 지원
  - 패널 헤더를 드래그해 분리하고 메인 창의 원래 패널 자리로 가져가면 다시 도킹됩니다.
  - 분리한 위치와 상태가 저장되며 메인 창을 숨기거나 다시 열 때 함께 동작합니다.
  - 분리 창에서도 팝업, 피커, 키보드 포커스, 실시간 미리보기와 저장이 똑같이 동작합니다.
  - 그리드 우클릭 `위치 초기화`로 분리 패널 위치를 되돌릴 수 있습니다.

### 편집 및 Undo/Redo 개선

- 안정 요소 ID 기반 편집 구조 도입
  - 요소를 생성, 복제, 붙여넣기, 이동, 리사이즈하거나 속성을 바꿀 때 대상이 어긋나거나 다른 요소에 잘못 적용되지 않습니다.
  - 키, 통계, 그래프, 노브, 플러그인 요소를 함께 선택해 이동, 크기 변경, 표시 전환, 그룹 편집을 할 수 있습니다.
  - 드래그와 일괄 편집에서 생긴 여러 변경을 Undo/Redo 한 번으로 되돌릴 수 있습니다.
  - 탭 프리셋, 커스텀 탭, 플러그인 요소가 섞인 편집도 같은 히스토리에서 처리됩니다.
  - 앱을 종료하거나 재시작할 때 모든 창의 미확정 편집을 먼저 저장하며, 저장에 실패하면 종료를 취소합니다.

- 요소 삭제 흐름 간소화
  - 확인창 없이 즉시 삭제되며, 필요하면 Undo로 복구할 수 있습니다.

- 캔버스 조작 개선
  - 요소를 더블 클릭하면 해당 속성 편집으로 바로 이동합니다.
  - 요소 이동 드래그와 그라디언트 축 조작을 Pointer 캡처로 전환해 커서가 창 밖으로 나가도 드래그가 끊기지 않습니다.
  - 여러 요소를 이동할 때도 캔버스 배율과 관계없이 같은 그리드에 정확히 스냅됩니다.
  - 중앙 스냅도 현재 그리드 간격을 따르며, `그리드 스냅 크기`를 0으로 설정하면 스냅을 끌 수 있습니다.
  - 토글 스위치는 노브를 직접 드래그해서도 켜고 끌 수 있으며 짧은 클릭과 드래그를 구분합니다.
  - 그리드 우클릭 메뉴를 기능별 묶음과 서브메뉴로 정리했습니다.

- 숫자 입력 확장
  - 방향키로 값을 조절하고 `+`, `-`, `*`, `/`, 괄호가 들어간 수식을 계산할 수 있습니다.
  - 숫자 입력 앞의 라벨을 좌우로 드래그해 값을 빠르게 조절할 수 있습니다.
  - 드래그와 방향키 조작 중에는 화면만 즉시 갱신하고 조작이 끝날 때 한 번 저장합니다.
  - 일괄 편집에서 값이 서로 다르면 `Mixed`로 표시되며, 색상 피커에서는 한쪽 축만 `Mixed`일 때 반대 축 편집이 잠깁니다.

### 다중 키 매핑

- 키 요소 하나에 여러 입력 매핑 [Issues 71](https://github.com/DmNote-App/DmNote/issues/71)
  - `개별 입력`은 등록한 키 중 하나만 눌러도 반응합니다.
  - `동시 입력`은 등록한 키를 모두 누르고 있는 동안에만 반응합니다.
  - 키보드, 마우스, HID 버튼(Windows)을 한 슬롯 안에서 섞어 쓸 수 있습니다.
  - 매핑 팝업에서 키를 추가, 제거하고 반응 방식을 바로 선택할 수 있습니다.

### 색상, 이미지 및 폰트

- 그라디언트 색상 추가
  - 키, 통계, 그래프, 노브의 배경과 테두리, 카운터, 키와 통계의 글자, 노트 본체와 테두리, 노트 글로우에 단색 또는 그라디언트를 적용할 수 있습니다.
  - 색상 피커에서 형식을 바꾸고 색상 스톱과 불투명도를 편집할 수 있습니다.
  - 노트를 제외한 요소는 캔버스 위의 축 핸들을 드래그해 그라디언트 방향을 조절할 수 있습니다.
  - 피커에서 편집 중인 색상도 캔버스에 즉시 미리보기됩니다.
  - `노트 색상 따라가기`를 켜면 글로우 색이 노트 본체 색을 자동으로 따라갑니다.

- 그림자 편집을 전용 컨트롤로 통합
  - 키와 노브는 대기 및 입력 상태별로, 통계는 대기 상태의 그림자 색상, 위치, 흐림을 한 곳에서 조절할 수 있습니다.
  - 단일 선택과 일괄 선택 모두 같은 방식으로 편집할 수 있습니다.

- 커스텀 이미지 배치 확장
  - `이미지만` 배치는 기존 키 표면과 라벨을 이미지로 대체합니다.
  - `키 위에` 배치는 기존 키 위에 이미지를 별도 레이어로 표시합니다.
  - 대기 및 입력 상태마다 이미지 맞춤, 위치, 회전, 크기를 따로 설정할 수 있습니다.
  - 이미지 피커 미리보기에 실제 배치와 변형이 그대로 반영됩니다.
  - 커스텀 CSS 변수로 이미지 맞춤, 변형, 레이어 순서를 추가로 조정할 수 있습니다.

- 폰트 굵기 선택 추가
  - 로컬 폰트와 웹 폰트가 지원하는 굵기를 분석해 목록에 표시합니다.
  - 키, 통계, 카운터의 폰트 굵기를 지정할 수 있으며 기존 Bold 설정과 자연스럽게 함께 동작합니다.
  - 같은 family에 속한 여러 폰트 face를 탭 프리셋으로 가져올 수 있습니다.

### 사운드, 폰트 및 모션 관리

- 사운드 피커에서 사운드 직접 관리
  - 편집, 이름 변경, 숨기기, 숨김 해제, 삭제를 지원합니다.
  - 파형 편집기에서 재생 구간을 자르고 Space 키로 미리 들을 수 있습니다.
  - 사용자 사운드를 삭제하면 해당 사운드를 사용하던 요소의 연결도 안전하게 해제됩니다.

- 키 사운드 출력 장치 목록에 시스템 출력 장치 추가
  - 시스템 출력 장치를 목록에서 직접 선택할 수 있으며 Windows ASIO 장치도 같은 목록에 함께 표시됩니다.

- 폰트 피커에서 로컬 폰트와 웹 폰트 직접 관리
  - 폰트 추가, 수정, 이름 변경, 활성화, 삭제를 지원합니다.
  - 웹 폰트 CSS를 편집하는 동안 실제 글꼴을 실시간으로 미리 볼 수 있습니다.
  - 확장자가 아니라 파일 내용을 검사해 이미지와 폰트를 불러옵니다.

- 카운터 모션 편집기를 전체 화면 시트로 개편
  - 실제 키 미리보기를 보면서 스케일, 지속 시간, 베지어 값을 편집할 수 있습니다.
  - 내장 모션과 사용자 모션을 한 목록에서 확인하며 사용자 모션의 추가, 수정, 삭제 흐름을 정리했습니다.

### 커스텀 탭 및 CSS

- 커스텀 탭 목록을 팝업 안 플랫 리스트로 정리
  - 탭을 추가, 선택, 삭제할 수 있습니다.

- 탭별 CSS 적용과 CSS 히스토리
  - 탭마다 다른 CSS 파일을 적용하고 현재 CSS를 파일로 내보낼 수 있습니다.
  - 최근에 불러온 CSS 파일을 히스토리에서 다시 적용하거나 목록에서 제거할 수 있습니다.

- 메인 창의 커스텀 CSS 적용 범위를 그리드 미리보기로 격리
  - 사용자 CSS가 설정, 속성 패널, 팝업, 숫자 입력 UI를 의도치 않게 변경하지 않습니다.
  - `@import`, `:is()`, `:where()`, `@font-face`가 섞인 CSS 처리와 URL 검증을 강화했습니다.

### 플러그인 기능 확장

- 플러그인 설정 Section API 추가
  - 플러그인이 앱과 같은 모양의 설정 섹션, 입력 컨트롤, 조건부 표시 항목을 선언할 수 있습니다.

- 플러그인 컨텍스트 메뉴 및 표시 요소 확장
  - 키와 그리드 우클릭 메뉴에 플러그인 명령을 추가할 수 있습니다.
  - 플러그인 표시 요소는 영구 ID를 사용하며 일반 요소와 함께 선택, 이동, 리사이즈, 숨김, 그룹화할 수 있습니다.
  - 플러그인 요소의 위치와 크기를 속성 패널에서 숫자로 입력하거나 라벨 드래그로 조절할 수 있습니다.
  - 오버레이 상태에 따라 메뉴와 표시 요소의 동작을 다르게 정의할 수 있습니다.

- 플러그인 Editor API 추가
  - `dmn.editor`로 현재 편집 문서를 읽고 여러 변경을 한 번에 저장할 수 있습니다.
  - 커밋된 변경을 구독해 메인 창, 오버레이, OBS 사이의 상태를 동기화할 수 있습니다.
  - Resource API와 Sound API의 관리 기능, 오류 계약을 공식 문서에 추가했습니다.

- 플러그인 실행 및 데이터 수명주기 강화
  - 플러그인 인스턴스와 설정 저장을 백엔드의 단일 상태 기준으로 동기화합니다.
  - 플러그인을 제거할 때 설정과 인스턴스 데이터를 함께 삭제할지 선택할 수 있습니다.
  - 명시적으로 리로드하면 파일 내용이 같아도 플러그인이 다시 실행됩니다.

### 오버레이 및 플랫폼

- 오버레이 위치 초기화 추가, 최대 창 크기 확대
  - 화면 밖으로 나간 오버레이를 겹침이 가장 큰 모니터의 작업 영역 가운데로 되돌립니다.

- 키 표시 지연을 최대 30초까지 설정
  - 지연 중 탭 전환, 키 해제, 설정 변경에도 입력 순서와 노트 길이가 유지됩니다.

- macOS 앱 서명 및 공증 적용
  - Apple Developer ID로 서명하고 공증받아 터미널에서 `xattr` 명령을 실행하지 않아도 바로 설치하고 실행할 수 있습니다.
  - 서명이 고정되어 다음 버전부터는 업데이트해도 손쉬운 사용과 입력 모니터링 권한이 그대로 유지됩니다.
  - 1.6.1 이하에서 업데이트하면 macOS가 다른 앱으로 인식하므로 두 권한을 한 번만 다시 추가해 주세요.

- 인텔 맥 지원 [Issues 125](https://github.com/DmNote-App/DmNote/issues/125)
  - macOS 빌드를 유니버설 바이너리로 전환해 인텔 맥과 애플 실리콘 맥에서 같은 DMG를 사용합니다.

- macOS 고주사율 디스플레이 지원 [Issues 122](https://github.com/DmNote-App/DmNote/issues/122)
  - 120Hz 이상 디스플레이에서 오버레이와 편집 화면이 더 부드럽게 갱신됩니다.
  - @AL-Pinecore 님이 [macOS 고주사율 디스플레이 지원](https://github.com/DmNote-App/DmNote/issues/122)에 기여해주셨습니다. 🎉

- macOS 자동 업데이트 추가
  - 설정에서 자동 업데이트를 켜거나 끌 수 있습니다.
  - DMG 다운로드, 검증, 설치, 재시작 진행 상태를 화면에서 확인할 수 있습니다.
  - 설치는 원자 교체 방식이라 도중에 실패해도 기존 앱이 그대로 남습니다.

## Fix

### 저장, 복구 및 Undo/Redo

- 키 매핑 변경, 초기화, 프리셋 적용, Undo/Redo 도중 아직 저장되지 않은 최신 카운터 값이 과거 값으로 돌아가던 문제 수정
- 카운터를 초기화해 저장하는 동안 새로 들어온 키 입력이 유실되던 문제 수정
- 편집 저장을 메인 스레드 밖 FIFO 실행기로 이전해 연속 입력 중 화면이 멈추거나 저장 순서가 뒤집히던 문제 수정
- 키 입력 경로에서 store 잠금을 제거해 입력과 키음 재생이 저장 작업에 막히지 않도록 개선
- 전체 초기화와 탭 초기화를 하나의 트랜잭션으로 처리해 일부 데이터만 초기화되던 문제 수정
- 프리셋 불러오기에서 요소 ID, 폰트, 이미지, 사운드, CSS 경로를 안전하게 다시 연결하도록 개선
- 구형 프리셋의 잘못된 크기 값이 검증 없이 통과하던 문제 수정
- 손상된 저장 데이터를 항목 단위로 최대한 복구하고 그 직후 정상 자산이 정리 대상으로 잘못 판정되던 문제 수정
- 이미지, 사운드, 폰트 파일을 즉시 삭제하지 않고 세션별 휴지통에 30일 격리하도록 변경
- 저장 파일 교체, 자산 복원, 실패 롤백을 원자적으로 처리해 충돌이나 크래시 뒤 일부 상태만 남던 문제 수정
- 노브에 적용한 커스텀 이미지가 재실행 후 사라지던 문제 수정 [Issues 91](https://github.com/DmNote-App/DmNote/issues/91)
- 사운드, 이미지, 카운터 모션, 플러그인 데이터를 삭제한 뒤 과거 Undo/Redo가 이미 삭제된 참조를 복원하던 문제 수정

### 패널, 팝업 및 입력

- 모달이 열린 동안 배경의 캔버스, 툴바, 단축키가 조작되던 문제 수정
- 모달이 다른 화면을 덮을 때 body 포털 드롭다운과 팝업이 그대로 남아 있던 문제 수정
- 팝업이 화면 가장자리나 작은 창 밖으로 벗어나던 문제 수정
- 빈 키 슬롯을 복사하거나 붙여넣지 못하던 문제 수정

### 렌더링 및 성능

- 오버레이를 처음 열 때 키, 카운터, 노트, 플러그인 요소가 제각각 다른 시점에 나타나던 문제 수정
- 키 입력 모드 전환과 오버레이 재동기화 도중 눌린 상태나 대기 중인 키, 카운터 갱신이 유실되던 문제 수정
- 내부 카운터의 불필요한 레이어와 구독을 줄이고 카운터 팝 모션을 컴포지터 애니메이션으로 전환
- 노트 캔버스를 화면 배율에 맞춰 렌더링하고 최소 안티앨리어싱 영역을 확보해 경계가 흐리거나 잘리던 문제 수정
- 그리드 이동, 리사이즈, 마퀴, 미니맵, 색상 트랙, 파형, 패널 입력을 프레임 단위로 병합해 빠른 연속 조작의 지연 감소
- 설정, 탭, 토글, 드롭다운, 모달, 팝업이 사용자 입력 직후 시각 상태를 먼저 반영하도록 개선
- 노트 라운딩 최솟값을 0으로 조정하고 기본 글로우 범위를 10으로 변경
- 짧은 노트가 표시 경계에서 갑자기 사라지거나 길이가 끊겨 보이던 문제 수정
- OBS WebSocket에 저지연 전송 옵션을 적용해 키 이벤트 전달 지연을 줄임 [Issues 72](https://github.com/DmNote-App/DmNote/issues/72)

### 색상, 이미지, 폰트 및 CSS

- 이미지가 손상되거나 로드에 실패했을 때 키 전체가 비거나 다른 이미지가 오류로 표시되던 문제 수정
- GIF를 WebP로 자동 변환하지 않고 원본 형식 그대로 저장하도록 변경
- 이름을 읽을 수 없는 폰트는 파일명을 대신 사용해 불러오도록 개선
- 시작 시 이미 삭제된 CSS 파일 때문에 watcher 등록과 앱 초기화가 실패하던 문제 수정

### 플러그인 및 OBS

- 플러그인 JavaScript 실행 실패를 성공으로 표시하거나 오류 안내가 잘려 보이던 문제 수정
- 플러그인이 상태를 갱신할 때마다 키뷰어의 눌림 표시가 깜빡이던 문제 수정 [Issues 111](https://github.com/DmNote-App/DmNote/issues/111)
- 플러그인 `onMount` 예외가 오버레이 전체를 비우던 문제 수정
- 실패했거나 제거된 플러그인의 늦은 저장이 새 실행 상태를 덮어쓰던 문제 수정
- 플러그인이 사용하는 `window`의 네이티브 메서드, 비동기 컨텍스트, 기존 전역 API 호환성 복구
- 플러그인 추가, 제거, 리로드 도중 부작용과 데이터가 남던 문제 수정
- OBS 이벤트를 한 곳에서 전달하고 command allowlist와 프로토콜 버전 검사 강화

### 운영체제 및 앱 수명주기

- Windows에서 앱을 재시작하면 오버레이 표시 상태가 바뀌던 문제 수정
- macOS 오버레이가 화면 위쪽에 닿지 않고 빈 공간이 남던 문제 수정 [Issues 121](https://github.com/DmNote-App/DmNote/issues/121)
  - `화면 모서리에 맞추기` 기준을 작업 영역에서 화면 끝으로 정정해 독과 작업 표시줄 영역만큼 떠 있던 여백 제거
  - 노트 효과를 끄면 상단에 예약되던 트랙 높이를 창 높이에서 함께 제외
- macOS 앱 메뉴에 종료 항목을 추가하고 Dock 종료, 재시작, 헬퍼 프로세스 정리 안정화
- macOS에서 앱 실행 중 접근성 권한 요청창이 저절로 뜨지 않도록 변경
- 파일과 프리셋 선택창을 호출한 창에 붙는 비동기 다이얼로그로 통일해, 취소를 실패로 알리거나 UI를 막던 문제 수정
- 내장 키음 `하잇` 앞부분의 무음 구간 제거
- 기타 버그 수정
