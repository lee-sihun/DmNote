# macOS 설치 및 권한 설정 가이드

## 1. 설치 후 "손상되어 열 수 없습니다" 오류

앱을 처음 실행할 때 다음과 같은 메시지가 표시될 수 있습니다:

> **"DM NOTE"이(가) 손상되었기 때문에 열 수 없습니다.**

### 해결 방법

**터미널**을 열고 다음 명령어를 실행하세요:

```bash
sudo xattr -cr /Applications/DM\ NOTE.app
```

- 비밀번호 입력을 요구하면 macOS 로그인 비밀번호를 입력하세요
- 명령어 실행 후 앱을 다시 실행하세요

> **참고:** 이 오류는 macOS Gatekeeper 보안 정책 때문에 발생하며, 앱이 Apple의 공식 공증(Notarization)을 거치지 않았을 때 나타납니다.

---

## 2. 권한 설정

DM NOTE가 키보드 및 마우스 입력을 캡처하려면 두 가지 권한이 필요합니다:

### 필수 권한

1. **손쉬운 사용(접근성)** — Accessibility
2. **입력 모니터링** — Input Monitoring

### 설정 방법

앱 실행 시 **손쉬운 사용(접근성)** 권한 요청 팝업을 자동으로 표시하지 않습니다. 입력 모니터링을 포함한 두 권한을 다음 순서로 직접 설정하세요:

1. **시스템 설정**(System Settings) 앱을 엽니다
2. **개인정보 보호 및 보안**(Privacy & Security)로 이동합니다
3. **손쉬운 사용**(Accessibility)을 클릭합니다
   - `+` 아이콘을 클릭하여 DM NOTE.app을 추가합니다.
4. **입력 모니터링**(Input Monitoring)을 클릭합니다
   - `+` 아이콘을 클릭하여 DM NOTE.app을 추가합니다.

### ⚠️ 중요: 앱 재시작 필수

권한을 부여한 후에는 **DM NOTE를 완전히 종료하고 다시 실행**해야 권한이 적용됩니다.

---

## 3. 새 버전 설치 시 주의사항

DM NOTE의 새 버전을 설치할 때 권한이 작동하지 않을 수 있습니다.

### 문제 증상

- 기존에 권한을 허용했는데도 키 입력이 캡처되지 않음
- 설정에서 DM NOTE 권한이 이미 활성화되어 있지만 작동하지 않음

### 해결 방법

새 버전 설치 후 **기존 권한을 제거하고 다시 추가**해야 합니다:

1. **시스템 설정** → **개인정보 보호 및 보안**으로 이동
2. **손쉬운 사용**(Accessibility)을 엽니다
   - **DM NOTE**를 선택하고 `-` 아이콘을 클릭하여 제거합니다
3. **입력 모니터링**(Input Monitoring)을 엽니다
   - **DM NOTE**를 선택하고 `-` 아이콘을 클릭하여 제거합니다
4. **DM NOTE 앱을 완전히 종료**합니다
5. DM NOTE를 다시 실행하고 [2. 권한 설정](#2-권한-설정) 섹션의 방법으로 권한을 다시 추가합니다
6. 앱을 재시작합니다

> **참고:** 이 문제는 앱이 Apple Developer ID로 서명되지 않았기 때문에 발생합니다. 매번 새 버전 설치 시 macOS가 다른 앱으로 인식하여 권한이 초기화됩니다.

---

## 문제 해결

### 앱이 열리지 않음

```bash
sudo xattr -cr /Applications/DM\ NOTE.app
```

### 키 입력이 캡처되지 않음

1. 두 권한(손쉬운 사용 + 입력 모니터링)이 모두 활성화되어 있는지 확인
2. 앱을 완전히 종료하고 재시작
3. 새 버전 설치 후라면 위의 "3. 새 버전 설치 시 주의사항" 참고
