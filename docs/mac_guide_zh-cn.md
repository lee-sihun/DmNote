# macOS 安装和权限设置指南

## 1. 权限设置

DM NOTE 需要两个权限来捕获键盘和鼠标输入：

### 必需权限

1. **辅助功能(Accessibility)**
2. **输入监控(Input Monitoring)**

### 设置方法

首次运行应用程序时，会自动显示**辅助功能**权限请求弹窗。

**输入监控**权限可能不会显示弹窗，因此需要手动设置：

1. 打开**系统设置**(System Settings)应用程序
2. 进入**隐私与安全性**(Privacy & Security)
3. 点击**辅助功能**(Accessibility)
   - 点击 `+` 图标添加 DM NOTE.app
4. 点击**输入监控**(Input Monitoring)
   - 点击 `+` 图标添加 DM NOTE.app

### ⚠️ 重要：必须重启应用程序

授予权限后，必须**完全退出并重新启动 DM NOTE** 才能使权限生效。

## 2. 1.6.1 及更早版本的相关问题

> [!WARNING]
> **1.6.1 及更早版本未使用 Apple Developer ID 签名，也未经过公证(Notarization)。**
>
> 此问题是由于 macOS Gatekeeper 安全策略引起的，安装新版本时 macOS 会将其识别为不同的应用程序，导致权限被重置。2.0.0 及更高版本已解决此问题，如无特殊原因，建议使用[最新版本](https://github.com/DmNote-App/DmNote/releases/latest)。

### 2-1. 安装后出现"已损坏，无法打开"错误

首次运行应用程序时，可能会显示以下消息：

> **"DM NOTE" 已损坏，无法打开。**

打开**终端**并运行以下命令：

```bash
sudo xattr -cr /Applications/DM\ NOTE.app
```

- 提示输入密码时，请输入 macOS 登录密码
- 运行命令后重新启动应用程序

### 2-2. 更新后权限不工作

- 即使之前已授予权限，但键盘输入仍无法捕获
- 设置中 DM NOTE 权限已启用但不工作

此时必须**删除现有权限并重新添加**：

1. 进入**系统设置** → **隐私与安全性**
2. 打开**辅助功能**(Accessibility)
   - 选择 **DM NOTE** 并点击 `-` 图标将其删除
3. 打开**输入监控**(Input Monitoring)
   - 选择 **DM NOTE** 并点击 `-` 图标将其删除
4. **完全退出 DM NOTE**
5. 重新启动 DM NOTE 并按照 [1. 权限设置](#1-权限设置) 部分的方法重新添加权限
6. 重启应用程序

## 故障排除

### 无法捕获键盘输入

1. 确认两个权限(辅助功能 + 输入监控)都已启用
2. 完全退出并重启应用程序
3. 如果是从 1.6.1 及更早版本更新，请参考上面的 [2-2. 更新后权限不工作](#2-2-更新后权限不工作)

### 应用程序无法打开

如果使用 1.6.1 及更早版本，请参考上面的 [2-1. 安装后出现"已损坏，无法打开"错误](#2-1-安装后出现已损坏无法打开错误)
