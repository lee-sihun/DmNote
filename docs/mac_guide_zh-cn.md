# macOS 安装和权限设置指南

## 1. 安装后出现"已损坏，无法打开"错误

首次运行应用程序时，可能会显示以下消息：

> **"DM NOTE" 已损坏，无法打开。**

### 解决方法

打开**终端**并运行以下命令：

```bash
sudo xattr -cr /Applications/DM\ NOTE.app
```

- 提示输入密码时，请输入 macOS 登录密码
- 运行命令后重新启动应用程序

> **注意：** 此错误是由于 macOS Gatekeeper 安全策略引起的，当应用程序未经过 Apple 官方公证(Notarization)时会出现此提示。

---

## 2. 权限设置

DM NOTE 需要两个权限来捕获键盘和鼠标输入：

### 必需权限

1. **辅助功能(Accessibility)**
2. **输入监控(Input Monitoring)**

### 设置方法

应用启动时不会自动显示**辅助功能**权限请求弹窗。请按以下步骤手动设置包括输入监控在内的这两项权限：

1. 打开**系统设置**(System Settings)应用程序
2. 进入**隐私与安全性**(Privacy & Security)
3. 点击**辅助功能**(Accessibility)
   - 点击 `+` 图标添加 DM NOTE.app
4. 点击**输入监控**(Input Monitoring)
   - 点击 `+` 图标添加 DM NOTE.app

### ⚠️ 重要：必须重启应用程序

授予权限后，必须**完全退出并重新启动 DM NOTE** 才能使权限生效。

---

## 3. 安装新版本时的注意事项

安装新版本的 DM NOTE 时，权限可能会失效。

### 问题症状

- 即使之前已授予权限，但键盘输入仍无法捕获
- 设置中 DM NOTE 权限已启用但不工作

### 解决方法

安装新版本后，必须**删除现有权限并重新添加**：

1. 进入**系统设置** → **隐私与安全性**
2. 打开**辅助功能**(Accessibility)
   - 选择 **DM NOTE** 并点击 `-` 图标将其删除
3. 打开**输入监控**(Input Monitoring)
   - 选择 **DM NOTE** 并点击 `-` 图标将其删除
4. **完全退出 DM NOTE**
5. 重新启动 DM NOTE 并按照 [2. 权限设置](#2-权限设置) 部分的方法重新添加权限
6. 重启应用程序

> **注意：** 此问题是因为应用程序未使用 Apple Developer ID 签名。每次安装新版本时，macOS 会将其识别为不同的应用程序，导致权限被重置。

---

## 故障排除

### 应用程序无法打开

```bash
sudo xattr -cr /Applications/DM\ NOTE.app
```

### 无法捕获键盘输入

1. 确认两个权限(辅助功能 + 输入监控)都已启用
2. 完全退出并重启应用程序
3. 如果是安装新版本后出现问题，请参考上面的"3. 安装新版本时的注意事项"
