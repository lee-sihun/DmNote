# Overlay API

`dmn.overlay` controls the overlay visibility, lock state, resize anchor, and size.

## Read state

### get()

Returns the current overlay state.

```javascript
const state = await dmn.overlay.get();
console.log('Visible:', state.visible);
console.log('Locked:', state.locked);
console.log('Anchor:', state.anchor);
```

## Control state

### setVisible(visible)

Shows or hides the overlay.

```javascript
await dmn.overlay.setVisible(true);
await dmn.overlay.setVisible(false);
```

### setLock(locked)

Locks or unlocks the overlay. A locked overlay ignores pointer input and cannot be moved or resized by the user.

```javascript
await dmn.overlay.setLock(true);
await dmn.overlay.setLock(false);
```

### setAnchor(anchor)

Sets the fixed point used when resizing the overlay.

<Callout type="info">
  Supported values: `top-left`, `top-right`, `bottom-left`, `bottom-right`, and
  `center`.
</Callout>

```javascript
await dmn.overlay.setAnchor('top-left');
await dmn.overlay.setAnchor('center');
await dmn.overlay.setAnchor('bottom-right');
```

### resize(payload)

Resizes the overlay and returns the bounds actually applied. The position may move to keep the selected anchor fixed.

```typescript
interface ResizePayload {
  width: number;
  height: number;
  anchor?: string;
  contentLeftOffset?: number;
  contentTopOffset?: number;
  fixedPositionDeltaX?: number;
  fixedPositionDeltaY?: number;
}
```

```javascript
const bounds = await dmn.overlay.resize({
  width: 800,
  height: 200,
});
console.log('Applied bounds:', bounds);
```

<Callout type="info">
  Width and height are clamped to the supported 100 to 4096 range. OBS has no
  native overlay window, so this call is rejected there.
</Callout>

### resetPosition()

Moves an off-screen overlay back to the center of the current monitor work area and returns the applied bounds.

```javascript
const bounds = await dmn.overlay.resetPosition();
console.log('Restored bounds:', bounds);
```

<Callout type="info">
  OBS has no native overlay window, so this call is rejected there.
</Callout>

## Events

### onVisibility(listener)

```javascript
const unsub = dmn.overlay.onVisibility(({ visible }) => {
  console.log(visible ? 'Overlay shown' : 'Overlay hidden');
});
dmn.plugin.registerCleanup(unsub);
```

### onLock(listener)

```javascript
const unsub = dmn.overlay.onLock(({ locked }) => {
  console.log(locked ? 'Overlay locked' : 'Overlay unlocked');
});
```

### onAnchor(listener)

```javascript
const unsub = dmn.overlay.onAnchor(({ anchor }) => {
  console.log('New anchor:', anchor);
});
```

### onResized(listener)

```javascript
const unsub = dmn.overlay.onResized((bounds) => {
  console.log(`Position: ${bounds.x}, ${bounds.y}`);
  console.log(`Size: ${bounds.width} x ${bounds.height}`);
});
```

<Callout type="warning">
  `dmn.overlay` does not provide an API for moving the overlay to an arbitrary
  coordinate.
</Callout>
