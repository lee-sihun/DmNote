# 노브 API

노브 요소 — HID 기기 축(예: 리듬게임 컨트롤러의 노브)에 바인딩되어 물리
노브와 함께 회전하는 시각화 요소 — 를 관리합니다. HID 기기의 **버튼**은
키보드 키와 완전히 동일하게 매핑·시각화되고, **축**은 전용 노브 요소로
시각화됩니다.

<Callout type="info">
  HID 입력 인식은 현재 **Windows**에서만 지원됩니다.
</Callout>

## 식별자

DmNote는 HID 입력에 고정 문자열 식별자를 부여합니다:

| 종류 | 형식 | 예시 |
| --- | --- | --- |
| 버튼 | `HIDB:vid:pid:usagePage:usage` | `HIDB:1ccf:101c:9:3` |
| 축 | `HIDA:vid:pid:usagePage:usage` | `HIDA:1ccf:101c:1:48` |

버튼 식별자는 키 라벨로 사용되며(일반 키보드 키처럼 매핑 가능,
`dmn.keys.onRawInput`에서 `device: 'gamepad'`로 전달) 축 식별자는 노브
요소의 `axisId`에 저장됩니다.

## 타입

```typescript
// KeyPosition의 스타일 필드를 상속 (위치, 크기, 색상, 이미지 등)
type KnobItemPosition = KeyPosition & {
  axisId: string; // 바인딩된 HID 축("HIDA:..."), 미바인딩이면 빈 문자열
  sensitivity: number; // raw 1단위당 화면 회전 도수
  reverse: boolean; // 회전 방향 반전
};

// 탭/모드 id(예: "4key")별 맵
type KnobItemPositions = Record<string, KnobItemPosition[]>;
```

자주 사용하는 상속 스타일 필드:

- `backgroundColor` / `activeBackgroundColor` — 대기 / 회전 중 배경색
- `borderColor` / `activeBorderColor` — 대기 / 회전 중 테두리 색상
- `borderWidth` — 테두리 두께(px, 기본 3)
- `borderRadius` — 모서리 반경(px), 미지정 시 원형
- `inactiveImage` / `activeImage` — 대기 / 회전 중 커스텀 이미지
- `idleTransparent` / `activeTransparent` — 배경 투명 토글

물리 노브가 회전하는 동안 요소는 키의 눌림처럼 입력(active)
색상/이미지로 전환되며, `누적 델타 × sensitivity`도 만큼 회전합니다.

## 위치 관리

### `dmn.knobItems.getPositions(): Promise<KnobItemPositions>`

전체 탭의 노브 요소 레이아웃을 반환합니다.

```typescript
const positions = await dmn.knobItems.getPositions();
console.log(positions['4key']); // "4key" 탭의 노브 요소들
```

### `dmn.knobItems.updatePositions(positions): Promise<KnobItemPositions>`

노브 요소 레이아웃을 교체하고 저장합니다.

```typescript
const positions = await dmn.knobItems.getPositions();
positions['4key'][0].sensitivity = 2.8125; // 노브 1회전당 화면 2회전
await dmn.knobItems.updatePositions(positions);
```

### `dmn.knobItems.onPositionsChanged(callback): Unsubscribe`

노브 레이아웃 변경(`knobPositions:changed`)을 구독합니다.

```typescript
const unsub = dmn.knobItems.onPositionsChanged((positions) => {
  console.log('노브 레이아웃 변경', positions);
});
```
